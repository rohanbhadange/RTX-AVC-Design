# 2026-11-02 — Communications USB allocation (R3.5 W-100)

**Change type:** live electrical wiring-model integration  
**Status:** schematic-integrated; physical hardware/airworthiness not certified  
**Decision:** [ADR-0001](../decisions/ADR-0001-sik-jetson-usb.md)  
**Snapshot:** [W-100 R3.5 model JSON](../../snapshots/wiring-studio/W-100_R3.5_2026-11-02.json)

## Before
- Holybro SiK 915 MHz radio connected to Pixhawk TELEM1 using discrete 5V/TX/RX/GND nets via JST GH 6-pin.
- Jetson USB3 A1 -> D455; Jetson USB3 A2 -> IMC614 USB isolator -> RoboClaw.
- Pixhawk RCIN -> RadioMaster R81 independent pilot override.

## After
- Jetson USB3 Type-A #2 -> single USB-A-to-Micro-B factory cable -> SiK V3 915MHz 100mW. This is the sole radio power/data connection. Micro-B is the Holybro-published 100mW connector, replacing the user's provisional USB-C note.
- One Jetson internal USB2 host GH5 -> physical pin1 VBUS +5V, pin2 D-, pin3 D+, pin4 GND, pin5 shield -> passive USB-A female adapter -> existing BasicMicro IMC614 isolator via factory cable -> existing RoboClaw. D-/D+ are explicitly grouped as a USB2 twisted differential pair. The socket's cavity 6 in the *logical* model is only an annotated factory-cable aggregate; it is not a real connector pin.
- Pixhawk TELEM1 SiK harness, 4 wire nets and the isolated radio TELEM connector representation removed. TELEM1 remains an unused physical port.
- Jetson USB3 A1 -> D455 unchanged. Pixhawk RCIN -> R81 safety receiver unchanged. All unrelated W-100 power, propulsion, gripper, sensor, BrainChip and storage nets preserved.
- Radio hardware documentation includes 28x53x10.7mm enclosure (sans antenna), 23.5g with antenna, nominal 5V 100mA TX/25mA RX, RP-SMA 2dBi antenna, outward-facing/adjustable RF mount, and a cable disconnect accessible without frame disassembly.

**Interpretation:** net count rises because the five physical USB2 wires are explicitly documented; no separate SiK power conductor/regulator or USB hub was introduced. There are no remaining SiK->Pixhawk TELEM1 nets. Existing DRC errors are primarily unmeasured cable lengths and unassigned terminations, not evidence of this specific USB topology failing. The additional missing-contact diagnostic concerns a conceptual/USB plug; do not treat it as a real crimp requirement.

## Packaging and test checklist
- [ ] Mount SiK at exposed frame edge with 2dBi antenna clear of carbon/motors, sufficient rotation/placement options, USB disconnect access, retention and strain relief
- [ ] Record actual purchased radio connector and cable type (Holybro 100mW default is Micro-B)
- [ ] Build and continuity-test short GH5 to USB-A female adapter against **host** pin numbering, polarity and shield configuration
- [ ] Verify no electrical short/ground-isolation bypass through IMC614 and no RoboClaw backpower when actuator 12V is off
- [ ] Boot combined load: D455 USB3 stream, SiK serial data, RoboClaw USB2 motion telemetry, BrainChip inference
- [ ] Use stable Linux device names (`/dev/serial/by-id/` or udev rules); never rely on variable `ttyUSB0` index
- [ ] Confirm radio pair protocol, air/ground frequency settings, packet loss, arena-range coverage and orientation
- [ ] Confirm independent R81/Pixhawk kill and RC failsafe while Jetson radio or compute is disconnected
- [ ] Measure harness lengths; update W-100 and mass/CG BOM
